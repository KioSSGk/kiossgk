# 🎉 Welcome to Our Kiossgk!! 🎉

## 🚀 프로젝트 소개 (Project Overview)
이 프로젝트의 이름은 **유니버셜 키오스크**이며, 남녀노소 장애, 비장애 누구나 사용할 수 있도록 만들어진 키오스크입니다.
> This project is called **Universal Kiosk**, and it is designed so that anyone, regardless of age, gender, or disability, can use it.

사람이 많아 복잡한 푸드코트와 같은 곳에서 **휴대폰**으로 누구나 **음식을 주문**할 수 있도록 설계되었습니다.
> It is designed so that anyone can order food through their phone in busy places like food courts.

## 🛠️ 기능설명 (Features)

### 🔑 어드민(Admin)
- **회원가입 / 로그인:** 새로운 어드민 계정 생성 및 로그인 기능.  
  _**Sign Up / Login:** Ability to create a new admin account and log in._
- **가게 생성:** 새로운 가게를 등록하고 관리할 수 있는 기능.  
  _**Create Store:** Ability to register and manage new stores._
- **메뉴 CRUD:** 메뉴 생성(Create), 읽기(Read), 수정(Update), 삭제(Delete) 기능.  
  _**Menu CRUD:** Create, Read, Update, Delete functionalities for menus._
- **옵션 CRUD:** 옵션 생성(Create), 읽기(Read), 수정(Update), 삭제(Delete) 기능.  
  _**Option CRUD:** Create, Read, Update, Delete functionalities for options._
- **매출 관리:** 일별/월별 매출 통계 확인 기능.  
  _**Sales Management:** Ability to check daily/monthly sales statistics._
- **주문 관리:** 실시간 주문 확인, 알림, 상태 변경 및 주문 내역 관리 기능.  
  _**Order Management:** Real-time order checking, notifications, status changes, and order history management._

### 👥 유저(User)
- **가게 조회:** 사용자가 가게 목록을 조회할 수 있는 기능.  
  _**Store Search:** Function for users to browse a list of stores._
- **메뉴 조회 및 상세:** 가게에서 제공하는 메뉴를 조회하고, 메뉴 상세 정보를 확인하는 기능.  
  _**Menu Browsing and Details:** Function to browse menus offered by stores and view detailed menu information._
- **옵션 선택:** 메뉴의 옵션을 선택하여 주문을 커스터마이즈할 수 있는 기능.  
  _**Option Selection:** Ability to customize orders by selecting menu options._
- **장바구니:** 선택한 메뉴를 장바구니에 추가하고, 결제를 준비하는 기능.  
  _**Cart:** Function to add selected menus to the cart and prepare for payment._
- **결제:** 다양한 결제 옵션을 통해 주문 결제 기능 제공.  
  _**Payment:** Provides payment functionality with various payment options._
- **주문 상태 알림:** 주문 상태에 따른 실시간 메시지 알림 기능.  
  _**Order Status Notifications:** Real-time message notifications according to order status._
